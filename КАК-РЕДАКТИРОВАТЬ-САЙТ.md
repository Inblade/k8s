# Как редактировать и управлять сайтом

Эта инструкция написана для человека, **далёкого от программирования**.
Вам **не нужно** знать код. Главный принцип простой:

> **Вы пишете, что хотите изменить, обычными словами — Claude всё делает и публикует.**

---

## 1. Самый простой способ — через Claude (рекомендуется)

Просто опишите задачу своими словами. Примеры фраз, которые работают:

- «Поменяй на главной странице заголовок на: *Акварель Юлии Кочетовой*»
- «На странице "Участие" добавь пункт: подать заявку нужно до 1 сентября»
- «Замени текст в разделе "О проекте" на этот: …» (и вставьте текст)
- «Добавь это фото на страницу "Финалисты"» (и приложите фото)
- «Сделай кнопку зелёной», «Добавь новую страницу про мастер-классы»
- «Поменяй почту для связи на mymail@example.com»

Claude сам найдёт нужный файл, внесёт изменения и опубликует их.
Вам ничего открывать и настраивать не нужно.

### Как добавить фотографии
1. Пришлите фото прямо в чат **или** загрузите их в папку `assets/images/`.
2. Напишите, на какую страницу и в какое место их поставить.

---

## 2. Где что находится (если захотите заглянуть сами)

Каждая страница сайта — это отдельный файл. Менять можно прямо на GitHub
(кнопка «карандаш» ✏️), но проще просто попросить Claude.

| Страница на сайте        | Файл                  |
|--------------------------|-----------------------|
| Главная                  | `index.html`          |
| О проекте Step by Step   | `step-by-step.html`   |
| Правила участия          | `rules.html`          |
| Финалисты / участники    | `participants.html`   |
| Программа фестиваля       | `festival.html`       |
| Книга Gold Edition       | `gold-edition.html`   |
| Контакты                 | `contact.html`        |
| Внешний вид (цвета/шрифты)| `assets/css/style.css`|
| Фотографии               | `assets/images/`      |

### Метки «ЗАМЕНИТЬ»
Сейчас на страницах есть **жёлтые пометки** вида `ЗАМЕНИТЬ текст`.
Это места, куда нужно вставить ваши настоящие тексты и фото.
Просто пришлите Claude правильный текст/фото для каждой такой метки —
и пометки исчезнут.

---

## 3. Как менять текст прямо на GitHub (без Claude)

Если хотите сделать мелкую правку сами:

1. Откройте нужный файл на GitHub (например `index.html`).
2. Нажмите значок карандаша ✏️ (*Edit this file*).
3. Найдите нужный текст и измените его. Текст находится между угловыми
   скобками, например: `<h1>Здесь заголовок</h1>` — меняйте только то,
   что **между** `>` и `<`.
4. Внизу нажмите зелёную кнопку **Commit changes**.
5. Через 1–2 минуты сайт обновится автоматически.

> ⚠️ Не трогайте символы `<`, `>`, `=` и кавычки — это «каркас» страницы.
> Если что-то сломалось — просто напишите Claude «верни как было».

---

## 4. Как опубликовать сайт в интернете (бесплатно, GitHub Pages)

Сайт — это обычные файлы, их бесплатно публикует **GitHub Pages**.
Настроить нужно **один раз**:

1. На GitHub откройте репозиторий → вкладка **Settings**.
2. Слева выберите **Pages**.
3. В разделе *Build and deployment* → *Source* выберите **Deploy from a branch**.
4. Branch: выберите ветку (например `main`), папку оставьте `/ (root)`.
   Нажмите **Save**.
5. Через пару минут GitHub покажет адрес сайта вида
   `https://<имя>.github.io/<репозиторий>/`.

### Свой домен jkochetova.com
Когда захотите подключить настоящий адрес `jkochetova.com`:
1. В *Settings → Pages → Custom domain* впишите `jkochetova.com`.
2. У регистратора домена пропишите DNS-записи на GitHub Pages.
3. Файл `CNAME` с доменом Claude создаст по вашей просьбе.

Просто скажите Claude: «помоги подключить домен jkochetova.com» — он
проведёт по шагам.

---

## 5. Что делать, если что-то сломалось

- Напишите Claude: **«верни как было»** или **«откати последнее изменение»**.
- Все версии сайта хранятся в истории GitHub — ничего не теряется навсегда.

---

## Коротко

1. Хотите изменение → **напишите словами в чат**.
2. Фото → **пришлите в чат**.
3. Опубликовать → один раз включите **GitHub Pages** (раздел 4).
4. Сломалось → **«верни как было»**.

Этого достаточно, чтобы полностью управлять сайтом без знания кода.
