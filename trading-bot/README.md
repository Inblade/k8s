# Binance Trading Bot

Простой торговый бот для спотового рынка Binance. Стратегия — пересечение
скользящих средних (MA crossover) с фильтром по RSI, плюс стоп-лосс и тейк-профит.

> ⚠️ **ДИСКЛЕЙМЕР.** Это учебный проект, а не финансовый совет. Автоматическая
> торговля криптовалютой **сопряжена с высоким риском полной потери средств**.
> На сумме ~270$ комиссии (≈0.1% за сделку) и проскальзывание заметно съедают
> результат. Никакая стратегия не гарантирует прибыль. Используй на свой риск.
> Начни с `DRY_RUN` и `TESTNET`, переходи на реальные деньги только осознанно.

## Что внутри

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа, запуск бота |
| `config.py` | Конфигурация из `.env` |
| `strategy.py` | Индикаторы (SMA, RSI) и логика сигналов |
| `exchange.py` | Обёртка над Binance API (+ режим DRY_RUN) |
| `trader.py` | Главный цикл, риск-менеджмент, состояние позиции |
| `backtest.py` | Прогон стратегии на исторических данных |

## Установка

```bash
cd trading-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Три уровня безопасности

1. **Бумажная торговля (по умолчанию).** `DRY_RUN=true` — бот считает сигналы и
   логирует «сделки», но НЕ отправляет ордера. Ключи не нужны.
2. **Testnet.** `TESTNET=true`, `DRY_RUN=false` — реальные ордера, но в тестовой
   сети с ненастоящими деньгами. Ключи бери на https://testnet.binance.vision/
3. **Боевой режим.** `TESTNET=false`, `DRY_RUN=false` — реальные деньги.
   Только когда ты всё проверил и понимаешь риски.

## Запуск

```bash
# Бэктест на истории (безопасно, без ключей):
python backtest.py BTCUSDT 1h 1000

# Сам бот:
python main.py
```

Бот логирует в консоль и в `bot.log`. Состояние позиции хранится в `state.json`,
поэтому при перезапуске бот «помнит», находится ли он в позиции.

## Настройка под ~270$

В `.env`:
- `TRADE_QUOTE_AMOUNT=250` — тратить 250 USDT на сделку (оставь запас на комиссии).
- `STOP_LOSS_PCT` / `TAKE_PROFIT_PCT` — управление риском на сделку.
- `INTERVAL=15m` или `1h` — на коротких таймфреймах больше шума и комиссий.

## Безопасность ключей

- API-ключам выдавай **только** право «Spot Trading».
- **НИКОГДА** не включай право вывода средств (Withdrawals).
- По возможности ограничь ключи по IP.
- Файл `.env` уже в `.gitignore` — не коммить его.

## Рекомендации перед реальными деньгами

1. Прогони `backtest.py` на разных периодах — пойми поведение и просадки.
2. Поработай неделю+ в `DRY_RUN`, сверь сигналы с графиком.
3. Переходи на `TESTNET`, убедись, что ордера исполняются корректно.
4. Только потом — реальные деньги и маленькая сумма.
