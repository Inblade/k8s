# Binance Trading Bot

Торговый бот для спотового рынка Binance с двумя стратегиями на выбор:

- **`dca`** (по умолчанию) — «умное» усреднение: базовый ордер + докупки на
  просадках со снижением средней цены входа и тейк-профитом на весь объём.
  Рекомендуется для маленького счёта: мало сделок → мало комиссий.
- **`swing`** — пересечение скользящих средних (MA crossover) с фильтром по RSI,
  плюс стоп-лосс и тейк-профит.

Стратегия выбирается параметром `STRATEGY` в `.env`.

> ⚠️ **ДИСКЛЕЙМЕР.** Это учебный проект, а не финансовый совет. Автоматическая
> торговля криптовалютой **сопряжена с высоким риском полной потери средств**.
> На сумме ~270$ комиссии (≈0.1% за сделку) и проскальзывание заметно съедают
> результат. Никакая стратегия не гарантирует прибыль. Используй на свой риск.
> Начни с `DRY_RUN` и `TESTNET`, переходи на реальные деньги только осознанно.

## Установка

```bash
cd trading-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Три уровня безопасности

1. **Бумажная торговля (по умолчанию).** `DRY_RUN=true` — бот считает сигналы и
   логирует «сделки», но НЕ отправляет ордера. Ключи не нужны.
2. **Testnet.** `TESTNET=true`, `DRY_RUN=false` — реальные ордера, но в тестовой
   сети с ненастоящими деньгами. Ключи бери на https://testnet.binance.vision/
3. **Боевой режим.** `TESTNET=false`, `DRY_RUN=false` — реальные деньги.
   Только когда ты всё проверил и понимаешь риски.

## Запуск

```bash
# Бэктест на истории (безопасно, без ключей):
python backtest.py dca   BTCUSDT 1h 1000   # DCA-стратегия
python backtest.py swing BTCUSDT 1h 1000   # swing-стратегия
# (без первого аргумента берётся STRATEGY из .env)

# Сам бот:
python main.py
```

## Как работает DCA-стратегия

Цикл:
1. **Базовый ордер** — первая покупка на `DCA_BASE_ORDER` USDT.
2. **Safety-ордера** — если цена падает на `DCA_PRICE_DEVIATION_PCT`% от цены
   последней покупки, бот докупает на `DCA_SAFETY_ORDER` USDT. Это снижает
   среднюю цену входа. Максимум — `DCA_MAX_SAFETY_ORDERS` докупок.
3. **Тейк-профит** — когда цена поднимается на `DCA_TAKE_PROFIT_PCT`% выше
   **средней** цены входа, бот продаёт весь объём и начинает цикл заново.

Множители `DCA_SAFETY_STEP_SCALE` и `DCA_SAFETY_VOLUME_SCALE` позволяют докупать
«реже, но крупнее» по мере углубления просадки.

## Адаптивный режим (подстройка под рынок + оптимизация)

Включается `ADAPTIVE_ENABLED=true`. Бот определяет режим рынка по наклону EMA и
волатильности и меняет поведение:

| Режим рынка | Что делает бот |
|-------------|----------------|
| Боковик | обычный DCA (он для боковика и создан) |
| Тренд вверх | повышает тейк-профит (`TREND_TP_MULTIPLIER`) — даёт прибыли «бежать» |
| Тренд вниз / высокая волатильность | **ставит новые входы на паузу** (не ловит падающий нож); открытая позиция продолжает управляться |

Параллельно (если `ADAPTIVE_OPTIMIZE=true`) бот каждые `REOPTIMIZE_EVERY` шагов
прогоняет бэктест набора параметров на свежей истории (`REGIME_LOOKBACK` свечей
таймфрейма `REGIME_INTERVAL`) и выбирает лучшие по доходности со штрафом за
просадку — это «обучение на лучших» (walk-forward оптимизация).

Текущий режим и активные параметры по каждой монете видны на дашборде.

> ⚠️ **Честно о границах.** Определение режима **запаздывает** и иногда ошибается
> (ложные сигналы на разворотах). Оптимизация параметров — это **подгонка под
> прошлое** (curve fitting): что было лучшим вчера, не обязано быть лучшим завтра.
> Поэтому перебор намеренно сужен и штрафует за просадку. Это инструмент снижения
> риска и адаптации, **а не гарантия прибыли**. Никакой «самообучающийся ИИ» не
> делает розничную торговлю стабильно прибыльной — относись к этому трезво.

## Тесты

Набор автотестов (без сети, биржа подменяется фейками) покрывает индикаторы,
DCA-движок, режимы рынка, оптимизатор, конфиг, журнал, вывод прибыли, адаптивный
контроллер, обёртку биржи и интеграцию трейдера:

```bash
python -m unittest test_bot -v
```

## Торговля разными монетами

Одна монета — параметр `SYMBOL`. Несколько сразу — `SYMBOLS` через запятую
(имеет приоритет). Бот ведёт по каждой монете отдельный DCA-цикл и состояние:

```
# одна монета
SYMBOL=ETHUSDT

# или несколько одновременно
SYMBOLS=BTCUSDT,ETHUSDT,SOLUSDT
```

Примеры пар к USDT: `BTCUSDT`, `ETHUSDT`, `SOLUSDT`, `BNBUSDT`, `XRPUSDT`,
`DOGEUSDT`, `ADAUSDT`, `AVAXUSDT`, `LINKUSDT`, `TONUSDT`.

> Бюджет: для DCA каждая монета может задействовать полный бюджет цикла
> (база + все докупки). Поэтому `бюджет_цикла × число_монет` не должен превышать
> `TRADE_QUOTE_AMOUNT` — иначе бот не запустится и подскажет уменьшить параметры.
> На ~$270 это значит: либо 1 монета с докупками, либо 2–3 монеты с уменьшенными
> `DCA_BASE_ORDER`/`DCA_SAFETY_ORDER`/`DCA_MAX_SAFETY_ORDERS`.

## Запуск как приложение (без терминала, macOS)

Самый удобный способ — оконное приложение: бот и дашборд работают внутри одного
окна, без терминала.

```bash
# один раз — создать иконку на рабочем столе:
./deploy/install-app-macos.sh
```

После этого на рабочем столе появится **TradingBot.app** — запускай **двойным
кликом**. Откроется окно с графиками, дашбордом и журналом; бот работает внутри.
Закрыть = закрыть окно. (Первый раз macOS может попросить подтверждение: правый
клик по иконке → **Open**.)

Логи при этом всё равно пишутся в `logs/<дата>/<час>.log`.

Запустить приложение можно и из консоли: `python app.py`.

## Запуск бота и дашборда вместе (macOS)

Чтобы открыть бота и дашборд сразу в двух окнах Terminal:

```bash
./deploy/run-all-macos.sh
```

Откроются два окна: в одном работает бот, в другом — дашборд
(http://localhost:8000). Логи бота пишутся в файлы с разбивкой по дням и часам:

```
logs/2026-06-09/11.log   # что бот делал 9 июня в 11:00–12:00
logs/2026-06-09/12.log
logs/2026-06-10/09.log
```

В консоли логи тоже видны. Старый одиночный `bot.log` больше не используется.

## Дашборд с графиками и журнал сделок

Бот пишет каждую сделку в `trades.csv`, а снимок капитала на каждом шаге — в
`equity.csv`. Веб-дашборд показывает это визуально: кривую капитала, цену с
метками покупок/продаж, текущий баланс, прибыль и журнал сделок.

```bash
# В отдельном окне терминала (бот пусть работает в первом):
source .venv/bin/activate
python dashboard.py
# открой в браузере http://localhost:8000
```

Дашборд обновляется сам каждые 15 секунд и просто читает CSV-файлы, поэтому
безопасно держать его рядом с ботом. (Журнал и графики пишет DCA-стратегия.)

## Автовывод части прибыли на кошелёк (TrustWallet)

При каждом прибыльном цикле бот откладывает `WITHDRAW_PROFIT_PCT`% прибыли в
резерв и, когда резерв достигает `WITHDRAW_MIN_AMOUNT`, выводит его на твой
адрес. Минимум нужен, чтобы вывод не съелся комиссией сети.

> ⚠️ **Безопасность.** Автовывод требует у API-ключа права **Enable
> Withdrawals** — это самое опасное право. Обязательно:
> - на Binance включи **белый список адресов вывода** (Address Management →
>   Whitelist) и в настройках ключа — «вывод только на адреса из белого списка»;
> - выводи на **дешёвую сеть** (по умолчанию USDT-TRC20, сеть `TRX`);
> - сеть на Binance и в TrustWallet **должна совпадать**, иначе средства потеряются.
>
> По умолчанию `WITHDRAW_ENABLED=false`. Без адреса вывод не включится.

Настройка в `.env`:
```
WITHDRAW_ENABLED=true
WITHDRAW_PROFIT_PCT=10
WITHDRAW_MIN_AMOUNT=15
WITHDRAW_ASSET=USDT
WITHDRAW_NETWORK=TRX
WITHDRAW_ADDRESS=твой_USDT_TRC20_адрес_из_TrustWallet
```

> На капитале ~$270 прибыль за цикл мала (несколько долларов), а минимальный
> вывод + комиссия сети ~1 USDT. Поэтому реально вывод будет происходить редко,
> накопленными порциями. Это нормально.

## Как завести $270 из TrustWallet на Binance (вручную)

Бот **не может** перевести деньги из твоего кошелька — это делаешь только ты в
приложении TrustWallet (подпись твоим ключом). Шаги:

1. На Binance: **Wallet → Deposit → Crypto**, выбери монету. Дешевле всего
   перевести как **USDT по сети TRC20 (TRX)**. Скопируй адрес депозита и **запиши
   выбранную сеть**.
2. Если в TrustWallet у тебя BTC, а не USDT — сначала поменяй BTC→USDT внутри
   кошелька (Swap) или переведи BTC как есть (тогда на шаге 1 выбери BTC и сеть
   Bitcoin; комиссия выше).
3. В TrustWallet: **Send**, выбери ту же монету/сеть, вставь адрес с Binance,
   укажи сумму, подтверди. **Сеть отправки и сеть депозита обязаны совпадать.**
4. Дождись подтверждений сети (USDT-TRC20 — минуты, BTC — дольше).
5. На Binance переведи средства на **Spot-кошелёк** и, если завёл BTC, поменяй
   нужную часть на **USDT** (бот торгует за USDT).

> ⚠️ Сначала переведи **маленькую тестовую сумму**, убедись, что дошло, и только
> потом весь остаток. Ошибка в сети/адресе = безвозвратная потеря средств.

## Круглосуточная работа на macOS

При старте (если `DRY_RUN=false`) бот сам проверяет ключи: связь с биржей,
валидность подписи, наличие права Spot и **отсутствие** права вывода средств —
и не запустится, если что-то не так.

Для работы 24/7 на Mac есть `launchd`-агент (автозапуск при входе + перезапуск
при сбое) и `caffeinate` (не даёт Mac уснуть):

```bash
cd trading-bot
./deploy/install-macos.sh        # установить и запустить агент
tail -f bot.log                  # смотреть логи
launchctl list | grep tradingbot # статус
./deploy/uninstall-macos.sh      # остановить и удалить
```

> ⚠️ **Закрытая крышка = сон.** `caffeinate` не даёт Mac уснуть, пока крышка
> открыта, но при закрытой крышке macOS всё равно засыпает, и бот встаёт.
> Чтобы работать с закрытой крышкой, выполни один раз:
> ```bash
> sudo pmset -a disablesleep 1     # вернуть: sudo pmset -a disablesleep 0
> ```
> Учитывай: ноутбук будет греться и тратить батарею; держи его на зарядке.
> Также бот остановится при перезагрузке Mac до момента твоего входа в систему
> (агент стартует при логине). Для по-настоящему надёжного 24/7 лучше VPS.

> Важно: DCA отлично усредняет в боковике и на коррекциях, но в затяжном падении
> safety-ордера заканчиваются, и позиция остаётся в минусе до отскока. Бюджет
> цикла (база + все докупки) не должен превышать `TRADE_QUOTE_AMOUNT` — это
> проверяется при старте.

Бот логирует в консоль и в `bot.log`. Состояние позиции хранится в `state.json`,
поэтому при перезапуске бот «помнит», находится ли он в позиции.

## Настройка под ~270$

В `.env`:
- `TRADE_QUOTE_AMOUNT=250` — тратить 250 USDT на сделку (оставь запас на комиссии).
- `STOP_LOSS_PCT` / `TAKE_PROFIT_PCT` — управление риском на сделку.
- `INTERVAL=15m` или `1h` — на коротких таймфреймах больше шума и комиссий.

## Безопасность ключей

- API-ключам выдавай **только** право «Spot Trading».
- **НИКОГДА** не включай право вывода средств (Withdrawals).
- По возможности ограничь ключи по IP.
- Файл `.env` уже в `.gitignore` — не коммить его.

## Рекомендации перед реальными деньгами

1. Прогони `backtest.py` на разных периодах — пойми поведение и просадки.
2. Поработай неделю+ в `DRY_RUN`, сверь сигналы с графиком.
3. Переходи на `TESTNET`, убедись, что ордера исполняются корректно.
4. Только потом — реальные деньги и маленькая сумма.
