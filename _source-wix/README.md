# Папка для исходников сайта с Wix

Сюда загрузите файлы старого сайта, чтобы Claude мог достать из них
тексты и фотографии и перенести на новый сайт.

## Что сюда класть (любой из вариантов)
- **Сохранённые страницы:** для каждой страницы в браузере `Ctrl+S` (Mac: `Cmd+S`)
  → тип файла **«Веб-страница полностью»**. Получится `.html` + папка с картинками —
  кладите сюда целиком.
- **PDF страниц:** «Печать → Сохранить как PDF» для каждой страницы.
- **Картинки:** оригиналы из Wix **Media Manager** (выделить всё → скачать).

## Как загрузить на GitHub
Кнопка **Add file → Upload files** в репозитории → перетащите файлы/папки сюда.

## Когда загрузите
Напишите Claude в чате **«готово»** — он разберёт файлы, перенесёт настоящий
контент на страницы сайта и уберёт метки `ЗАМЕНИТЬ`. После переноса эту папку
можно удалить.
