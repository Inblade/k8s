# Папка для исходников сайта с Wix

Сюда загрузите файлы старого сайта, чтобы ассистент мог достать из них
тексты и фотографии и перенести на новый сайт.

## Что сюда класть

### Для сохранения ДИЗАЙНА (внешнего вида)
- **Скриншоты всей страницы (самое важное):** по одному на каждую страницу.
  Chrome/Edge: `F12` → `Ctrl+Shift+P` → ввести `screenshot` →
  **«Capture full size screenshot»**. Или расширение *GoFullPage*.
  По желанию — ещё версия с телефона (для мобильного вида).
- **Логотип** отдельным файлом (PNG или SVG), если есть.
- Названия шрифтов и цвета (если знаете) — можно просто текстом.

### Для сохранения КОНТЕНТА (тексты + фото)
- **Сохранённые страницы:** для каждой страницы в браузере `Ctrl+S` (Mac: `Cmd+S`)
  → тип файла **«Веб-страница полностью»**. Получится `.html` + папка с картинками —
  кладите сюда целиком. (Из них ассистент достанет и тексты, и **точные цвета/шрифты**.)
- **PDF страниц:** «Печать → Сохранить как PDF» для каждой страницы.
- **Картинки:** оригиналы из Wix **Media Manager** (выделить всё → скачать).

## Как загрузить на GitHub
Кнопка **Add file → Upload files** в репозитории → перетащите файлы/папки сюда.

## Когда загрузите
Напишите ассистенту в чате **«готово»** — он разберёт файлы, перенесёт настоящий
контент на страницы сайта и уберёт метки `ЗАМЕНИТЬ`. После переноса эту папку
можно удалить.
